# SkipTheFirm - Atlanta Website Building & Automation Agency

A modern, responsive website showcasing SkipTheFirm's services in website development and business automation.

## 🚀 Features

- **Modern Design**: Clean, professional design with smooth animations
- **Responsive**: Optimized for all devices (desktop, tablet, mobile)
- **Performance**: Fast loading with optimized assets
- **Interactive Elements**: Animated counters, smooth scrolling, hover effects
- **SEO Ready**: Proper meta tags and semantic HTML structure

## 🛠️ Technology Stack

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Icons**: Font Awesome 6.0
- **Hosting**: Vercel
- **Development**: Live Server for local development

## 📦 Installation & Setup

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/kyleinatl/SkipTheFirmNew.git
cd SkipTheFirmNew

# Install dependencies
npm install
```

## 🏃‍♂️ Running the Project

### Local Development
```bash
# Start development server
npm start
# or
npm run dev

# The site will be available at http://localhost:8080
```

### Build for Production
```bash
npm run build
```

### Deploy to Vercel
```bash
# Deploy to Vercel
npm run deploy
# or
vercel
```
